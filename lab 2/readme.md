
# Lab2 — Image Processing

Приложение на C++ и Qt 6 для обработки изображений.

## Возможности

- Пороговая обработка методом итераций
- Пороговая обработка методом Оцу
- Медианный фильтр
- Фильтры минимума и максимума
- Выбор размера и формы ядра
- Сохранение результата обработки

## Запуск

1. Открой раздел Releases.
2. Скачай архив Lab2-Windows.zip.
3. Распакуй архив в отдельную папку.
4. Запусти Lab2.exe.

## Сборка из исходного кода

Требуются Qt 6, CMake и совместимый компилятор C++20.

Открой проект через CMake в Qt Creator,
выбери установленный комплект Qt и собери проект.

## Технологии

- C++20
- Qt 6 Widgets
- CMake
- Qt Concurrent
